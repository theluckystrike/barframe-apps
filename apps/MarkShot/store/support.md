# MarkShot Support

Use the menu bar viewfinder icon to capture Area, Window, or Full screen. Grant Screen Recording permission when asked. After changing permission, try capture again; if the system requires it, quit and reopen MarkShot. The Screen Recording settings button opens the relevant System Settings page.

Open Sample editor to try the tools without screen access. Choose a tool and click or drag on the image. Enter text before placing a text annotation. Crop commits on release; Undo restores the prior image. Copy PNG, Save PNG, and Drag PNG out export the flattened result.

Settings contains the save-folder chooser, launch at login, and the global shortcut. If a shortcut is unavailable or triggers another application, select another key or add Option. A saved folder that becomes unavailable must be selected again. History stores the last ten flattened images locally and can be cleared in the menu.
