# MarkShot Privacy Policy

MarkShot captures screens only after you grant Screen Recording permission and request a capture. The application processes screenshots and annotations locally. It does not collect data, track you, use analytics, or upload screenshots. No account is required.

The last ten captures are stored as PNG files inside the application’s sandbox. Edits, undo and redo automatically update the flattened history image. Copy, save and drag also update it. Older captures are removed as new captures exceed the history limit. Use Clear in the menu to delete capture history. A user-selected save folder is remembered with a security-scoped bookmark; saved exports remain where you put them until you delete them in Finder. Clear does not delete exported files or clear the system clipboard. Settings and bookmarks are stored locally. Choosing another save folder replaces the previous bookmark. The clipboard receives an image only when you choose Copy PNG. Dragging provides an image to the destination application you choose.

Screen Recording permission can be changed in System Settings. Sample mode uses a bundled synthetic image and needs no screen access. Launch at login is optional and off by default. Privacy Policy and Support open bundled text. Open website opens your web browser, which handles those page requests.
