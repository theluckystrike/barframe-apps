# PortSense Support

Click the cable icon in the menu bar. Use Try Sample to explore the Power, Connections and History tabs without hardware or accounts. Return to Live to read this computer. Refresh or Retry requests new readings. Missing hardware fields are shown as unavailable.

Enter the charger rating in Settings. Set zero to disable the comparison. Capacity and input telemetry are different readings; neither measures wall electricity. USB speeds are link ceilings and current figures are allocations or limits. A cable advisory is a suggestion to check a connection, not a cable diagnosis.

History keeps up to 60 recent readings. Live polling has a 15-second cadence; manual reads and failed attempts can add entries, and polling can wait for an active read. History resets on quit. A missing value or failure leaves a gap. Scroll the body to see all details; footer controls remain visible.

Open Settings with Command-comma. Use Include built-in devices to reveal internal USB devices. Launch at Login is optional and off by default. Read privacy is available without a web connection. Requires macOS 14 or later.

Support by Michael Lip. If a field is unavailable, try Refresh, reconnect the accessory, or test a direct connection. Use Sample to compare the interface with example readings. Hardware field availability varies by computer and accessory.
