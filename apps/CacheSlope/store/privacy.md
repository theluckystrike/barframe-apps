CacheSlope privacy policy

CacheSlope stores chosen folder names, security scoped bookmarks, logical file sizes, snapshot dates, and preferences locally on this Mac. It does not read file contents. It does not collect analytics, use accounts, or initiate network requests. The app only scans folders selected through the system folder chooser. Symbolic links are not followed and cloud files are not downloaded. Copies of reports may include folder names and are created only when you choose Copy report. Remove selected folders and their history or clear all folders from Settings. Sample data is fictional and separate from live folder history. Privacy and support links open the browser only when selected.
