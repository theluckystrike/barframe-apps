Open the menu bar item and choose Try Sample mode to explore the app without files or credentials. In live mode, choose a supported session log folder with Connect folder. In Settings, set your five-hour and seven-day token budgets; zero leaves a budget unset.

If usage is missing, check the selected format and folder, then Refresh. If access expired, reconnect the folder. Disconnect removes permission and cached counts without changing source logs. Pace estimates use the observed average and rolling event expiry; they are not official provider quotas.

Launch at Login is optional. If system approval is pending, approve the app in Login Items or toggle it off to cancel. Privacy Policy is available in About and the menu bar popover.

Bundled help is available offline from About > Support. For missing usage, reconnect the selected log folder and use Refresh. For privacy cleanup, use Disconnect in Settings for each connected format. This removes saved folder permission and cached counts while preserving source files and budgets.
