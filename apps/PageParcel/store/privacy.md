PageParcel Privacy Policy

PageParcel does not collect data. There are no accounts, advertising, analytics, telemetry or automatic network requests. PDF content is read locally using PDFKit. Selected file bookmarks, labels, expected page counts and packet order are stored in the app sandbox. Original files are never modified. Sample documents are synthetic and stay separate from the live packet.

Clear all local data removes both live and Sample packet state, saved bookmarks and settings without deleting original PDFs. Copy assembly sheet writes the visible report to the system clipboard only when requested. Other applications may read the clipboard. Support and Privacy Policy links open your browser and the website may receive normal browser requests.
