CaptionCove privacy policy

CaptionCove processes the SRT files you explicitly choose on your computer. Input files remain unchanged. The app stores file access bookmarks, selected filenames, language labels, rules and text free result summaries in its sandbox container. Dialogue is held in local memory during review and is not saved in project summaries. Sample fixtures are separate local files.

CaptionCove has no accounts, advertising, analytics, telemetry, cloud sync or automatic network requests. Its only dependencies are Apple system frameworks and the local MASKit screenshot and smoke helpers. It has no network entitlement. No data is collected by the developer.

Copy report places the shown report on the system clipboard. Dialogue is excluded unless you explicitly choose the option to include it. Other apps may access clipboard content under normal system behavior. Opening Support or Privacy opens your browser and can make a normal web request to barframe.com.

Forget Live project removes saved references and summaries. Delete all local data also removes local Sample fixtures and resets appearance, language and shortcut preferences. Source subtitle files are never deleted. Settings store appearance, interface language and shortcut preferences in local user defaults.
