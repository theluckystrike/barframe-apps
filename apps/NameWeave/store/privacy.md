# NameWeave privacy

Data Not Collected. NameWeave has no telemetry, analytics, accounts, advertising or networking dependency. Folder names, security scoped bookmarks, destination policy and proposed relative path plans remain on this Mac inside the sandbox container. Only explicitly chosen folders are read. File contents are not read and source files are never renamed or deleted.

Forget root removes its bookmark and saved plan. Clear local data removes app state and restores defaults without deleting source files. Sample uses synthetic in memory names and separate state. Copy plan writes the displayed names and reasons to the system clipboard only when requested. Other apps may access the clipboard and later sharing is controlled by the user.

Support and Privacy Policy open the browser at https://barframe.com/apps/nameweave/support/ and https://barframe.com/apps/nameweave/privacy/. The browser makes a normal web request. Contact information voluntarily sent through support is outside the app.
