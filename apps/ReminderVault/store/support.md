# ReminderVault Support
Developer: Michael Lip. Contact: support@barframe.com.

Open the menu bar checklist and enable Sample mode to explore local example tasks without accounts or Reminders permission. Preview sync, inspect each task's file, list, old values and proposed title, completion and due date, then apply. Check a task off after applying. Open Settings with Command-comma or the Settings button for the sync interval and optional launch at login.

For live use, choose your vault folder, connect Reminders and select writable lists. New vault tasks go to the first selected list alphabetically. Reminder imports go to ReminderVault Inbox.md. Imported title date-token text is escaped to preserve its literal meaning. Deletions are logged for manual review and are never propagated automatically.

If access is denied, enable ReminderVault in System Settings → Privacy & Security → Reminders. Reselect a moved vault folder. Copied rv IDs must be unique; remove the copied identifier comment from one task before previewing. A preview or sync failure pauses automatic sync: review and apply a successful preview to resume. Open Privacy Policy for storage, retention and deletion instructions.
