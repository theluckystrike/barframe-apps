CheckHarbor privacy policy

CheckHarbor stores repository names, workflow metadata, recovery episodes and preferences locally on your Mac. Optional access tokens stay in the system Keychain. Requests go to api.github.com and contain the configured repository name and optional token. Redirects are rejected. CheckHarbor never fetches source code or workflow logs. Opening a validated run link opens github.com in your browser. GitHub processes these requests under its own policies.

Recovered episodes are removed after the retention period chosen in Settings. Choose 7, 30 or 90 days. Pruning takes place during live refresh. Unresolved episodes remain until a matching recovery is observed or you delete local data. Acknowledge and Snooze do not delete an episode. Removing a repository stops monitoring and preserves its history.

Delete local history and repositories in Settings clears the local run metadata, episodes and repository list. It preserves your optional Keychain token. Remove credentials separately deletes the token. Sample history is fictional, isolated from live history, and can be reset with Reset Sample. Sample mode makes no network requests.

Opening the optional website link sends a normal browser request to the linked website, which follows its own privacy policy.

No analytics, advertising, developer backend or developer data collection are included.
