# KeyOverlap Privacy Policy

KeyOverlap stores shortcut records, explicit context assumptions and proposed replacements locally in its sandbox container. No plan data is transmitted to Barframe. The app has no account, analytics, advertising, tracking, cloud sync or network requests.

The import action reads a JSON file you select in the native file picker. It copies validated records into the local plan and retains no ongoing file access. The app does not monitor typing, read other apps or inspect their settings. A registered global shortcut opens this app only. Clipboard access writes text only when you choose a Copy button.

Sample mode uses fictional records and never overwrites your live plan. Clear local plans in Settings removes locally saved records and context assumptions. Launch at login is optional and starts disabled. Privacy and support links open your browser on request.

Contact support@barframe.com or visit https://barframe.com/apps/keyoverlap/support/ for help. Policy dated 2026-10-14.
