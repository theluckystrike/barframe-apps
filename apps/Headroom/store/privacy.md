# Privacy policy

Headroom Agent Memory processes system memory statistics and same-user process metadata locally. It reads process names, executable paths, ancestry, and, for version-named executables, the first argument to recognize supported agents. It does not save or transmit those names, paths, or arguments. The app displays aggregate counts and resident memory only. It has no account, advertising, analytics, tracking, or network entitlement. No personal data is collected by the developer. Sample mode uses synthetic readings. Settings are held in memory for the current session. The Privacy button displays this policy summary in the app. The external policy address is https://barframe.com/apps/headroom/privacy/ and support is https://barframe.com/apps/headroom/support/.
