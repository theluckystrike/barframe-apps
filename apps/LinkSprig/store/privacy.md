# LinkSprig Privacy Policy

Updated 2026-10-14

LinkSprig processes documentation on your computer. It does not collect data for the developer. There are no accounts, analytics, advertising, telemetry, cloud services or network entitlements.

You explicitly choose a folder to grant read access. The app reads directory metadata and UTF8 Markdown files within that root. It skips symbolic links and reports inaccessible descendants. It never modifies your source documents. Paths, selected targets, security scoped bookmarks, proposal settings and the last live result are stored locally in the app sandbox container. Raw document files are not copied into the container. A limited unchecked syntax excerpt can be retained in the local result to explain coverage limitations. Scans run on request. Returning to the app can check whether selected input metadata changed.

Sample uses synthetic documents in a separate container directory. It does not read a personal folder or reuse Sample findings as live results. Clear local data removes app saved state, bookmarks, saved results and Sample fixtures. It does not remove source files.

Copy change plan writes the visible report, including file paths and target names, to the system clipboard only when requested. Other applications may access the clipboard and any later sharing is under your control.

Privacy Policy and Support open your browser at the product website. Browser requests are handled by that website and browser. LinkSprig does not send documents with those requests.
